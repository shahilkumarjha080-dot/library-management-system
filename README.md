# Django Web Application Project

## Overview
A starter Django project with Django REST Framework and JWT authentication, featuring a basic frontend (login and dashboard) using Django templates. Backend API and models are ready for your collaborator to implement.

## Problem Being Solved
Demonstrates a full-stack web application with authentication, CRUD, and UI integration for learning and assignment purposes.

## Key Features
- User login page (frontend)
- Dashboard page (frontend)
- Django REST Framework and JWT authentication ready
- Project structure for backend API and CRUD

## Technology Stack
- Django / Django REST Framework
- Python
- SQLite (default, can be changed)
- HTML/CSS/JavaScript (Django templates)

## Installation Instructions
1. Clone repository
2. Create and activate a virtual environment:
   - `python -m venv venv`
   - Windows: `venv\Scripts\activate`
3. Install dependencies:
   - `pip install -r requirements.txt`
4. Run migrations:
   - `python manage.py migrate`
5. Start development server:
   - `python manage.py runserver`
